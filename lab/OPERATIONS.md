# Operations

- Originals are read-only inputs; candidate renders are always separate files.
- Batch runs resume by content hash + analysis/rubric version.
- Use `--force` after changing the rubric/provider or when intentionally refreshing evidence.
- Review logs for individual corrupt files; the batch continues.
- Keep the dashboard on loopback unless a reviewed authentication layer is added.
- Import performance as observations. Reported relationships are correlations, never causes.
- To reset generated lab state, archive `.lab_data/`; do not delete source media.
