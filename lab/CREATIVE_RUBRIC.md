# Pompom Creative Rubric

Rubric version: `pompom-action-dna-v1`

The strongest reference structure is:

`instant anomaly -> clear goal -> physical attempt -> resistance -> bigger attempt -> fake
success -> biggest character-impacting twist -> hard cut / natural loop`

Scores are 0-10 and must cite timestamped evidence. Looking, smiling, pointing, or standing
alone are not physical actions. Big/small/light/heavy is valuable only when it becomes one
consistent physical rule that blocks a character's goal.

| Dimension | What earns a high score |
|---|---|
| First-frame hook | Anomaly/action is readable by 0.8s |
| Problem readability | Viewer can identify what is wrong without setup |
| Character goal | A concrete want: sit, pass, catch, use, wear, control |
| Physical action | Frequent active verbs with visible consequence |
| Problem resistance | The rule visibly pushes back against the attempt |
| Escalation | Meaningful larger/different beat every 1-2s |
| Single physical rule | One consistent causal rule, no random gimmick pile-up |
| Fake resolution | Brief apparent success before the final beat when appropriate |
| Final twist | Biggest consequence affects the character and ends promptly |
| Loopability | Hard cut to frame one is coherent; no fade/black/CTA interruption |
| Pacing | Low dead-time percentage and no long passive holds |

## Creative Structure Match

- First-frame anomaly: 15%
- Clear character goal: 15%
- Physical character action: 20%
- Problem resistance: 15%
- Escalation: 15%
- Final twist: 10%
- Loopability: 5%
- Single-rule clarity: 5%

This 0-100 value is labelled **Creative structure match**. It is not viral probability,
expected views, or success probability.

## Classification

- **WINNER CANDIDATE:** high structure match, immediate anomaly, clear goal, active struggle,
  escalation, strong final, no severe continuity issue, and adequate semantic confidence.
- **GOOD:** structurally strong with minor repair needs only.
- **AVERAGE/FIXABLE:** central idea is usable and timestamp-level edits can repair identified
  problems.
- **BAD:** concept/action/readability is fundamentally weak, or existing footage cannot be
  responsibly repaired by editing.

Scores never act as the only threshold. Black openings, long dead time, severe continuity
defects, generic CTA tails, unreadable problems, and missing physical action are explicit
structural gates. Human review can confirm or override every classification.
