Pip the rabbit wants to place one sticky note on the toy cabinet's empty front panel. Pip reaches toward that panel, but the note clings to the fingertip while a visible gap remains between hand and cabinet. Pip peels with the other hand and the note splits into two, one on each hand. Each pull doubles the sticky notes from two to four to eight; the paired hands stay apart so each changed note count is visible before the next doubling, progressively covering Pip's arms and face. Pip turns the note-covered face toward the mirror, sees the reflection and gasps while both the face and reflected notes remain visible. Pip remains covered until a sneeze scatters the notes onto the cabinet's formerly empty front panel. Pip is relieved, but the cabinet remains messy.
