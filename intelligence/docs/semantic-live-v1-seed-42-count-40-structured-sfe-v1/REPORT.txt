Architecture

SHORT_FORM_ENGINE now separates evidence acquisition from one shared evaluator:
  TimedTextEvidenceSource / timed-text-v1
  StructuredCanonicalEvidenceSource / structured-canonical-v1
      -> ShortFormCanonicalEvidence
      -> short_form_engine._evaluate

There is no separate semantic scoring engine and no runtime copy of scoring formulas. The default remains timed text. Structured reports add provenance/recognition metadata; default/explicit timed-text reports retain their original bytes. The archived legacy-short-form-engine.py.txt is a test oracle, not a runtime engine.

The canonical evidence object contains beat features plus objective acquisition facts, declared/supported goal, opening, rule, trigger, payoff and loop dimensions. It also carries timing, dialogue load/dependence, reaction, staging/production risk signals, and structured source references. No source input can supply score, findings, penalties or PASS/REJECT decisions. The strict structured input schema accepts only Adapter V1 projection, selected story fields, actor and source-consistent timing carriers.

Structured acquisition consumes the existing Adapter V1 explicit fields. It independently verifies supported opening/rule/beat/payoff relations; declared fields do not become strong facts automatically. It uses source-field morphology/overlap, existing known rule patterns, and structural difference checks. At least two non-object rule anchors or a known rule-family match support linkage; a source rule also requires an opening link, trigger declaration and at least two linked consequences. Consequence similarity is checked at Jaccard 0.8, with new information independently supplied. These are versioned acquisition heuristics, not changes to creative PASS/REVISION/REJECT thresholds. Quoted claims/instructions are excluded from visual support. No provider rationale or suggested creative label enters this verification.

Source rule IDs identify concrete evidence, not new engine-taxonomy classes. All scoring weights, numerical score/threshold expressions, finding codes, penalties, historical comparison algorithm, and production gates remain authoritative. A present-unclassified rule/payoff can be evaluated on evidence of support/linkage/state change without inventing a taxonomy label. Unknown quality is not awarded full credit merely because a field exists.

Goal declaration without opening support receives the existing partial goal tier (55), while no declared/supported goal receives 0. Full goal credit still requires opening support. A declared payoff can receive the existing weak payoff value (15); presence alone does not qualify it for the existing strong-payoff tier. Provider loop suggestions do not become intentional-loop credit.
