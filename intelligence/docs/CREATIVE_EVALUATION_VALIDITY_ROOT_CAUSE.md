# Implementation

`creative-validity-v1` reuses the six CPQ dimensions and returns an explicit `PASS / FAIL / UNKNOWN / NOT_APPLICABLE` evidence outcome plus a bounded state. It includes:

- creative strengths with evidence;
- creative weaknesses and exact evidence;
- artificial-optimization indicators;
- production risks;
- visual, semantic and audience evidence limitations;
- canonical score and grade without reinterpretation;
- `STRUCTURALLY_COMPLIANT` separately from `CREATIVE_RISK_DETECTED`;
- `PROVISIONAL_CREATIVE_VALIDITY_REQUIRED` as the final qualification;
- official A+ fixed at `INACTIVE`.

The provenance contract accepts only `DETERMINISTIC_FIXTURE`, `REAL_AI_PROVIDER`, `HUMAN_AUTHORED` and `UNKNOWN_ORIGIN`. It stores provider/model, story and prompt source IDs, generator profile, generation timestamp, evaluator version, request/response fingerprints, reviewer origin/independence, canonical score, qualification and evidence completeness. Fixture and unknown origins are explicitly excluded from real capability statistics and official A+ calibration.

The story selection path still permits deterministic fixture candidates to exercise persistence and HTTP integration, but marks them `STRUCTURAL_INTEGRATION_FIXTURE_ONLY`. A real-provider review must carry `reviewerIndependent=true`; a provider's unsupported self-rating cannot pass that gate.
