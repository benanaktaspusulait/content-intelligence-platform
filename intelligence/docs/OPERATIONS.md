# Operations

Health endpoints are `/actuator/health` for Spring and `/health` for Python. Swagger UI is `/swagger-ui.html` in local profiles.

Back up the PostgreSQL volume and `data/` together. The database contains metadata and relative paths; a database-only restore is incomplete. Raw videos, imports, and model artifacts are append-oriented. Variants and reports may be regenerated when their recipes and versions are preserved.

Failed analysis jobs must record the error and retry count without aborting unrelated work. Do not delete locked predictions. Correct bad input with a new prediction or reconciliation event. Secrets belong in `.env` or the host environment.
