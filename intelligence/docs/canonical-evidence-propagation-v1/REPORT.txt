CANONICAL EVIDENCE PROPAGATION V1 — OFFLINE REPORT

Accepted output: verified-replay/. replay/ and replay-final/ are development snapshots; verified-replay includes final source/text binding, provenance and quality-scope clarification.
Architecture: stored normalized fields + accepted Structured Evidence Input V1 acquisition → source-bound canonical creative evidence context → independent SFE, Naturalness, Beat Grammar, ranking/admission, Creative Shape → existing production preselection.
No global score. No thresholds, score weights, enum vocabulary, model/compatibility data, prompts, or provider configuration changed. Default legacy and the prior structured-SFE-only mode remain unchanged. Canonical propagation requires an explicit context or canonicalCreativeEvidenceMode=v1.
The fact context is source independent: TIMED_TEXT, SEMANTIC, MANUAL. MANUAL uses the same strict structured field/provenance contract. Timed acquisition retains unknown facts as null; it does not fabricate trigger/payoff presence. Source kind is audit provenance and never a scoring preference.
Canonical facts are source-text declarations and deterministic support inferences, not observed pixels. Everyday goal support is the explicit goal + object + normal expectation fact, distinct from opening visibility and from a configured object-affordance quality match. Trigger/opening overlap and the existing structured goal/rule linkage checks do not prove semantic truth.
Input extra fields are forbidden; scores, pass/fail and admission cannot be supplied. Context is built from validated projection hashes/references and bound to exact timing carrier, candidate ID and ranking fields. Snapshots are copied for evaluator isolation.

EVALUATOR CHANGES
SFE: acquisition reused, _evaluate and thresholds untouched, exact report projection preserved. No SFE source edit.
Ranking: canonical mode replaces only legacy declared-goal lexical recognition/conflict acquisition. A declared goal must still be supported as ordinary use and visible in the opening. Insufficient visibility yields DECLARED_GOAL_UNSUPPORTED with canonical evidence. Required fields, source conflicts, all scores/weights/penalties/history remain active.
Naturalness: receives original goal, object, rule, opening, expectation, why-this-object, trigger and all shared fact receipts. Opening source support now comes from canonical facts, rather than separately parsing the frame through generic affordance patterns. Existing object categories, expected-behavior model, response regex classifier, policy lookup, quality formula and admission rules remain independent. Explicit normal expectation/why-this-object do not create an unconfigured compatibility policy.
Beat Grammar: receives exact source strategy/consequence/newInformation, reuses existing strategy/consequence categories only, removes fabricated generic body/contact/spatial states, keeps unstated physical states UNKNOWN. Existing UNKNOWN_CONSEQUENCE validation remains active. A BROKEN result with this code means classification coverage is unresolved, not that a consequence/rule/payoff is absent. All 18 encounter this existing coverage requirement. No taxonomy expansion and no quality promotion.
Creative Shape: derives its fingerprint from the same acquired beat facts; unknown physical relationships/payoff mechanism stay UNKNOWN. Presence is not mechanism classification. Production preselection uses newly evaluated Naturalness/BG/validation records through existing quality_reasons/curate/production selection. No forced raw rank or slate promotion.
