EXECUTIVE DIAGNOSIS

Primary classification: C — OPENING_EVALUATOR_COVERAGE_FAILURE.

The exact 35 is not a constant default. It is a real branch in the existing formula and all eight stored outputs reached it: canonical semantic acquisition marked goal, anomaly, trigger, and causal overlap present; the known direct-response branch did not support the opening, and the more demanding still-frame test also remained unresolved. In the eight stored records, un-generalized and generalized scores are both 35 and staticFrameLegibility is 25. This is a repeatable evidence-tier score, not a calibrated human judgment of opening quality.

Hand-authored strong fixtures scored 90 through both MANUAL canonical input and semantic structured projection. That proves the evaluator can produce high scores for a narrow pattern it already recognizes. It does not validate geometry-based openings such as rolling pressure making dough rise. The unfamiliar but explicit GOLD-OPENING-06 remains present/unclassified and is not turned into MISSING; it nevertheless receives only the low source-evidence branch because the opening still-frame acceptance test does not recognize its unfamiliar state contrast. The existing semantic path preserves the text and fields; evidence is lost at the evaluator's derived still-frame support decision, not at semantic field projection.

For the three rolling-pin seeds, the source text explicitly describes Mimi, a flattening goal, the rolling pin, downward pressure, a tall dough ridge/wall/column already under the barrel, and surrounding flat dough. Each is a single still-state description; none requires prior context or a future action to state the visible contradiction. The current evaluator does not classify pressing as its accepted `explicitUsePose` and does not compare flat-vs-tall geometry. Source text is stronger than the score says on these dimensions. This audit does not assign a new numeric quality rating or claim observed-pixel legibility. Separately, the three seeds are a clear diversity-collapse signal.

Why classification C, not A or D: the hand-authored positive controls show a functioning evaluator path and the source records contain explicit opening information, so generation weakness is not established by the score. The positive controls also show evidence coverage is asymmetric. No stored canonical “Lid opening” annotation suitable for calibration was found in the semantic experiment folders; the hand-authored controls serve as the calibration evidence. These findings do not prove that every seed is a good opening. They show that 35 alone cannot decide that question.

3. EXACT SCORING FORMULA AND COMPONENTS

No additive point components exist. The function emits branch values. The production structured/generalized path uses premise_naturalness.py’s `full_causal` branches, then premise_admission_evidence.py’s still-frame guard:

| Branch | Points | Exact condition |
|---|---:|---|
| covered direct cause + supported source | 90 | `direct and source_supported` |
| covered direct cause, no frame | 60 | `direct and not frame` |
| source facts overlap but direct cause unsupported | 35 | `source_supported` |
| otherwise | 15 | no supported source overlap |
| strong static contrast override | 90 | `sourceFunctionalContrastSupported and stillCausalLegibility == SUPPORTED` |
| guard clamp | 35 or 15 | preliminary score >=60 but still support unresolved; 35 when canonical causal overlap is true, else 15 |

The component decisions, with provenance, are:

| Evidence component | Max / points | Pass condition | Fail / unknown behavior | Source and canonical fields |
|---|---:|---|---|---|
| `direct` (configured cause/goal/trigger) | no independent points | existing object response policy, goal match, no noun conflict, natural trigger >=70 | absent/unknown policy yields false, not a semantic proof of poor idea | semantic rule, goal, trigger; `impossibleRule`, `everydayGoal`, `visibleTrigger`; affordance_expectations_v1 |
| `source_supported` (canonical opening overlap) | 35 branch | literal object + expected-use action + frame anomaly; with structured input, canonical `opening.causalRelationshipVisible` | false branch yields 15; missing/unknown support is not promoted | `frameZeroDescription`, structured `goal/opening/trigger` facts |
| `stillCausalLegibility` | no points itself | no motion/prior-context/text requirement; character, object, visible goal/problem; plus recognized source contrast or legacy static >=65 | unresolved remains `None`/UNRESOLVED; never inferred true from fact presence | `frameZeroDescription`, `everydayGoal`, `primaryObject`, candidate `protagonist`, baseline `staticFrameLegibility` |
| `sourceFunctionalContrastSupported` | 90 override | explicit-use pattern AND a fixed state/color contrast AND character/object/goal/anomaly/causal evidence | otherwise false; geometry differences outside fixed pair list are uncredited | `normalExpectation`, `everydayGoal`, `frameZeroDescription`, canonical goal/opening facts |
| motion / prior context / text dependency | veto only | no matching motion, prior-context, or explanatory-text pattern | matching motion/context/text prevents still-supported result; unknown is `None` | sanitized frame-zero source text |

Total possible under the ungeneralized legacy formula: 15, 35, 60, 90. In the current generalized structured opening/admission route, reachable branch totals are 15, 35, and 90; the 60 no-frame branch is clamped because no still-frame evidence can support it. 60 is therefore not accepted-floor reachable in this route. 80 and 100 are not emitted anywhere in the opening formula. Maximum emitted opening score is 90, not 100. The opening floor is 60. 35 is a natural conditional plateau: any source-supported but not `direct` result starts at 35; a score >=60 that fails the static guard is also reset to 35 when canonical causal overlap exists.

For the eight real cases the exact path is: `direct=false` → canonical `source_supported=true` → preliminary score 35; staticFrameLegibility=25 and no accepted still property contrast → still support unresolved → no override → final score remains 35. There were no points “earned then missed” in an additive ledger: 35 is the output of a categorical branch. This explains all eight identically without postulating a default constant.

8. PRESENCE, TAXONOMY, AND LEXICAL DEPENDENCE

Semantic evidence adapter maps frameZeroDescription and other allowed fields losslessly as source text (`semantic_evidence_adapter.py`, FIELD_MAP / `project`). Canonical acquisition projects source overlap, not truth. The opening quality code then applies additional vocabulary tests. `explicitUsePose` currently recognizes `mid.stroke`, `mid.swing`, `mid.sweep`, `flipping`, `striking`, `brushing`, and `painting`; it does not recognize `pressing`, `bearing down`, or `a barrel embedded against dough`. Functional contrasts are hard-coded to straight/bent, closed/open, open/closed, dry/wet, clean/dirty, and a narrow paint-color pattern. There is no geometry opposition such as flat/tall, sheet/wall, low/high or surface/column. `stillCausalLegibility` therefore stays unresolved despite present facts. This is analogous to an evidence-coverage issue, but unlike the historical SFE suppression case, the source fields survive and canonical opening presence booleans are true; the loss occurs in opening evaluator recognition/decision.

Response handling does preserve PRESENT_UNCLASSIFIED versus MISSING. The score does not, however, report a named “evidence present but still-frame matcher unsupported” component; 35 obscures that distinction unless the detailed receipt is inspected. The evaluator is taxonomy-coupled through `direct`, but does not require a known taxonomy label for every presence fact. The recognized static-contrast override can reach 90 even when no known response policy supports the premise, as GOLD-OPENING-04 demonstrates.
